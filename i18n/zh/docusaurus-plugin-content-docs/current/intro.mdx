# ZotFlow 中文文档

**Literature flows in, insight flows out.**

ZotFlow 把 Zotero 和 Obsidian 连成一个循环：文献库流入你的 vault，阅读、批注、思考都在 Obsidian 里发生，写作时引用能跳回原文精确位置——而每一处改动都会同步回 Zotero。Zotero 始终是文献库的 source of truth，Obsidian 是你思考发生的地方。

## 主循环

ZotFlow 功能很多，但全部服务于四个站点之一：

### ① 进 —— 同步文献库

连接 Zotero 账户，把条目、集合、附件、注释拉入本地缓存。在侧边栏 **Tree View** 中浏览、检索一切——首次同步后完全离线可用。

→ [安装、连接 Zotero 与首次同步](getting-started.md)

### ② 读 —— 批注不出走

用内置阅读器打开附件（与 Zotero 同一渲染引擎，主题随 Obsidian）。高亮、评论、摘取注释图片。vault 里的本地 PDF/EPUB 享受同等待遇——它们的注释存在旁车文件里，永不触碰 Zotero。

→ [阅读器与批注](reading-and-annotating.md)

### ③ 沉淀 —— 每个来源一张页面，你的文字有处安放

每个条目渲染为一张 **Source Note**：自动生成的汇总页，收纳元数据、注释摘录与子笔记。页面内的内容有三种所有者——**模板**在每次更新时重生成自己的部分；**Zotero 同步区域**（Item Note、注释评论）可编辑并随同步回流；**persist region** 完全属于你：仅存本地的区块，在每次重渲染中存活、永不离开 vault。跨文献的综合写在独立笔记里，用链接连回来。

→ [Source Note](source-notes.md) · [Item Note](item-notes.md)

### ④ 出 —— 边写边引

把条目拖进草稿，或输入触发字符插入引用——Pandoc、wikilink、脚注，或由 citeproc 渲染的真实 CSL 样式。链接在两侧都入乡随俗：在 Obsidian 中打开 ZotFlow reader，在 Zotero 中打开 Zotero reader。

→ [引用与写作流](citation-guide.md) · [CSL 引用](csl-citations.md)

循环自行闭合：④ 的引用跳回 ② 和 ③，② 的新批注自动刷新 ③，所有你选择同步的内容回流 Zotero。

## 术语表

- **Source Note**：为每个 Zotero 条目自动生成的 Markdown 汇总页，由 LiquidJS 模板渲染。骨架归模板所有；其中的可编辑区与 persist region 归你所有。
- **Item Note**：挂在条目下的 Zotero 原生子笔记——可在 ZotFlow 内创建、编辑、删除，同步回 Zotero。与 Source Note 是完全不同的概念。
- **Persist Region**：在模板中声明的 Source Note 区块，内容仅存本地——在每次重渲染中存活，永不同步到 Zotero。
- **Editable Region**：Source Note 中由 marker 围栏、可解锁编辑的区段。三种：Item Note 区域与注释评论区域（同步），以及 persist region（仅本地）。
- **Library Reader**：Zotero 库附件的阅读器；注释同步回 Zotero。
- **Local Reader**：vault 本地 PDF/EPUB/HTML 的阅读器；注释存于同址 `.zf.json` 旁车文件，永不触碰 Zotero。
